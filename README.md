# Crypto Tracker (Work in Progress)

This project tracks selected cryptocurrencies, analyzes market data, and automates simple trading actions (buy, sell, manage protection) based on configurable signals and risk controls. It aims to support:

- Monitoring prices and signals for specific coins
- Generating trade decisions from technical indicators
- Placing and managing orders with basic protections
- Recording performance and providing simple summaries

This README will be expanded when the project reaches a stable milestone.
