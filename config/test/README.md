# Test Configuration Files

This folder contains experimental and testing configuration files that are not needed for the main project operation.

## 📁 File Descriptions

### **Strategy Testing Configs**
- `aggressive_test.yaml` - Aggressive trading strategy testing
- `momentum_test.yaml` - Momentum strategy testing  
- `super_aggressive_test.yaml` - Super aggressive trading testing

### **Backtesting Configs**
- `backtest_advanced.yaml` - Advanced backtesting with realistic fees, slippage, and order book simulation

### **Paper Trading Configs**
- `paper.yaml` - Basic paper trading configuration
- `paper_24_7.yaml` - Standard 24/7 paper trading
- `paper_24_7_aggressive.yaml` - Aggressive 24/7 paper trading
- `paper_24_7_conservative.yaml` - Conservative 24/7 paper trading
- `paper_24_7_optimized.yaml` - Optimized 24/7 paper trading
- `test_paper_config.yaml` - Paper trading test configuration

### **Feature Testing Configs**
- `social_media.yaml` - Social media integration testing
- `crypto_discovery.yaml` - Crypto discovery feature testing

### **Configuration Examples**
- `config_detailed.yaml` - Detailed configuration example
- `config_line_by_line.yaml` - Line-by-line configuration example
- `config_minimal.yaml` - Minimal configuration example
- `config_per_coin.yaml` - Per-coin configuration example
- `config_verbose.yaml` - Verbose configuration example

## 🎯 Usage

These configs are for:
- **Testing different strategies** and parameters
- **Backtesting** with various configurations
- **Paper trading** experiments
- **Feature development** and validation
- **Configuration examples** and templates

## ⚠️ Important Notes

- These configs are **NOT used by the main system**
- They are **experimental/testing only**
- Use `config.yaml` for production
- Use `config_testing.yaml` for enhanced feature testing

## 🚀 Main Project Configs

The main project uses:
- `config.yaml` - Main production configuration
- `config_testing.yaml` - Enhanced testing configuration with all integrated features

## 📝 Migration Notes

These configs were moved here because they:
1. Are **test/experimental configurations** not needed for main operation
2. Were **deprecated** or **superseded** by the enhanced main system
3. Are **examples** or **templates** for reference only
4. Contain **outdated** or **incomplete** configurations

The enhanced main system now includes all advanced features (monitoring, LLM analysis, performance tracking, parameter optimization, enhanced reporting) that were previously scattered across these test configs.
