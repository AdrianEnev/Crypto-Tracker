# 🤖 LLM-Powered Market Analysis and Configuration Generator

This script uses advanced LLM (Large Language Model) analysis to examine current market conditions and generate optimal trading configurations for real-world trading. It combines real-time market data collection with sophisticated AI analysis to provide actionable trading recommendations.

## 🎯 Features

### **Comprehensive Market Analysis**
- **Real-time Price Data**: Collects current prices from multiple sources (CCXT, CoinGecko, CoinMarketCap)
- **Technical Indicators**: Calculates RSI, EMA, ATR, and other key indicators
- **Volatility Analysis**: Analyzes market volatility patterns and regimes
- **Trend Analysis**: Identifies uptrends, downtrends, and sideways markets
- **Volume Analysis**: Examines volume patterns and trends
- **Market Sentiment**: Determines overall market sentiment and strength

### **LLM-Powered Recommendations**
- **Optimal Thresholds**: AI-recommended price thresholds based on current market conditions
- **Risk Parameters**: Intelligent risk management settings (stop-loss, take-profit, position sizing)
- **Strategy Parameters**: Optimized RSI periods, EMA settings, ATR multipliers
- **Market Regime Adjustments**: Adaptive settings based on volatility and trend conditions
- **Coin-Specific Recommendations**: Tailored parameters for each cryptocurrency

### **Safety and Validation**
- **Fallback Mechanisms**: Graceful degradation when LLM is unavailable
- **Validation Checks**: Ensures generated configurations are safe and practical
- **Market-Based Adjustments**: Uses market data to adjust parameters even without LLM
- **Error Handling**: Robust error handling and recovery

## 🚀 Usage

### **Basic Usage**
```bash
python scripts/llm_config_generator.py
```

### **Custom Output Location**
```bash
python scripts/llm_config_generator.py --output config/my_optimized_config.yaml
```

### **Specific Coins Analysis**
```bash
python scripts/llm_config_generator.py --coins bitcoin ethereum solana cardano
```

### **Custom Base Configuration**
```bash
python scripts/llm_config_generator.py --config config/config.yaml --output config/llm_optimized.yaml
```

## 📊 Output

The script generates a comprehensive YAML configuration file with:

### **Global Parameters**
- Market regime assessment (bullish/bearish/neutral)
- Volatility regime (high/moderate/low)
- Recommended strategy (mean_reversion/momentum/breakout)
- Risk budget and position limits
- Confidence thresholds
- Volatility gate settings

### **Coin-Specific Settings**
- Optimized price thresholds
- Risk management parameters
- Strategy-specific parameters
- Enable/disable recommendations

### **Analysis Metadata**
- Generation timestamp
- Market regime analysis
- LLM reasoning and recommendations
- Source market data timestamp

## 🔧 Configuration Requirements

### **LLM Setup**
1. **OpenAI API Key**: Configure your OpenAI API key in the secrets
2. **Model Selection**: Uses GPT-4 by default (configurable)
3. **Rate Limiting**: Built-in rate limiting and error handling

### **Data Sources**
- **CCXT**: Real-time price data from Binance
- **CoinGecko**: Historical data and market information
- **CoinMarketCap**: Additional price validation

## 🔍 How It Works

### **1. Market Data Collection**
- Collects real-time prices from multiple sources
- Fetches historical data for technical analysis
- Calculates technical indicators (RSI, EMA, ATR)
- Analyzes volatility and volume patterns

### **2. Market Analysis**
- Determines overall market sentiment
- Identifies volatility regimes
- Analyzes trend patterns
- Calculates correlations between assets

### **3. LLM Analysis**
- Sends comprehensive market data to LLM
- LLM analyzes conditions and provides recommendations
- Parses LLM response for actionable insights
- Generates optimized configuration

### **4. Configuration Generation**
- Applies LLM recommendations to base configuration
- Validates parameters for safety
- Adds analysis metadata
- Saves optimized configuration
